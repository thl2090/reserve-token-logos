# Reserve DTF Token Logos

Public-facing logo assets for Reserve DTF tokens. Each logo has an SVG (scalable) plus 512px and 1024px transparent PNGs.

## Logos
- buildout (AI Infrastructure)
- neocloud
- photon (Photonics)
- power (Power Generation)
- robots (Robotics)
- mag7 (Reserve Magnificent 7 DTF)

## Files per logo
- `<name>.svg`
- `<name>_512x512.png`
- `<name>_1024x1024.png`

All PNGs have transparent backgrounds (RGBA).
